# Competitive Lifecycle Compatibility

This is an evidence snapshot, not a marketing comparison. It was refreshed on 2026-07-19 against Atoll's shipped source and Vibe Island's current public product pages and release feed. Vibe Island is proprietary; where its public material does not describe an event contract or cleanup rule, the result is **not publicly verifiable**, not an assumption that the feature is absent.

## Agent coverage

Atoll ships 12 source-linked integrations: Codex, Claude Code, Gemini CLI, GitHub Copilot CLI, Cursor Agent, Factory Droid, Qoder, Qwen Code, Pi, OpenCode, Hermes, and Amp. Vibe Island's [current agent list](https://vibeisland.app/) names all 12 of those plus ZCode, Antigravity CLI, Trae, MiMoCode, Grok Build, Kimi Code, DeepSeek, Mistral Vibe, CodeBuddy, WorkBuddy, Kiro, Oh My Pi, Gajae Code, and Kimi: 26 in total.

Agent count is therefore a clear Vibe Island advantage. Atoll's release bar is narrower: an integration is counted only when a stable primary contract and executable fixtures support conservative lifecycle mappings. See [Live Status Support](LIVE_STATUS_SUPPORT.md) for every Atoll boundary, event, config path, and version gate.

## Evidence-backed product bar

Atoll is demonstrably ahead in the parts that can be proven from shipped source and tests: conservative typed lifecycle mapping, distinct supported terminal outcomes, opt-in config preservation, crash-safe local delivery, and explicit stale-state/transition invariants. This is an advantage in auditability and bounded behavior; it is not evidence that Vibe Island's closed implementation lacks equivalent safeguards.

Vibe Island is demonstrably ahead in agent breadth, in-panel interaction, terminal navigation, SSH coverage, localization, and an already operating signed update channel. Atoll should not claim overall feature superiority while those gaps remain.

Parity is unresolved for Vibe Island's per-agent turn/session boundaries, exact failure-versus-cancellation fidelity, local trust/reload rules, queue durability, event ordering, TTL, terminal dwell, and tombstone behavior. The [1.0.42 changelog](https://vibeisland.app/changelog/) is useful behavioral evidence, but release-note fixes do not expose the underlying protocol well enough to score those rows.
